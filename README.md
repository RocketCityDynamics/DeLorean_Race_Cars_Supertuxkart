# DeLorean_Race_Cars_Supertuxkart
V1.1 of a playable widebody race car styled after the 80s DeLorean for SuperTuxKart 1.4 or 1.5. 

Clone entire folder to ~/.local/share/supertuxkart/addons/karts in Debian 13 on Pi4 or Linux desktop.

It should pop up as a playable car on the main menu and have a trackable icon moving around the course as you drive.
